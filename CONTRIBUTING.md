# Contributing to Raund

Thanks for improving the app. Please keep changes transparent, privacy-preserving, and compatible with the public-release gate in the README.

1. Do not add account credentials, tokens, device IDs, personal data, private API keys, signing files, or copied third-party assets to a change.
2. Add or update unit tests when behavior changes.
3. Run `./gradlew.bat testDebugUnitTest lintRelease` before opening a pull request.
4. Keep user-facing Turkish and English text aligned.
5. Do not add automated scraping of a source unless permission and terms have been verified.

Issues and pull requests must not claim Riot affiliation or promise account safety/ban outcomes.
